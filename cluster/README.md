## Cluster Science Archive Tutorials

This repository contains tutorial notebooks for the [Cluster Science Archive](https://csa.esac.esa.int/csa-web/).

The TAP URL of the CSA is

```
https://csa.esac.esa.int/csa-sl-tap/tap/
```

Run interactively on [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/HPA-ESDC-ESA-INT/HPA-Jupyter-Notebooks/HEAD)

### Requirements

Standard requirements, see `requirements.txt` in the [root of this repository](https://github.com/HPA-ESDC-ESA-INT/HPA-Jupyter-Notebooks/tree/main).

### Notebooks

The following notebooks are available:

-  [cluster_tap_metadata.ipynb](https://github.com/HPA-ESDC-ESA-INT/HPA-Jupyter-Notebooks/blob/main/cluster/cluster_tap_metadata.ipynb) - Access observation metadata in the SSA via TAP

In order to open the notebook locally, you can download them from the repository and run:

```
$ jupyter-notebook
```

The Jupyter Notebook will be opened in a browser. Note that the files downloaded from the notebook will be stored at the directory from where the notebook was launched.
